# Имран: Звёздный защитник — 3.0.0

Космическая аркада с кампанией, постоянным развитием ракеты и бесконечным режимом.

**Играть:** [Открыть игру](https://berdinov81-alt.github.io/imran-space-game/)

## Кампания и развитие

- 30 миссий в шести мирах: Земля, Марс, ледяной пояс, Вега, грозовой фронт и Улей.
- Пять типов построений флота, элитные противники, дополнительные задачи, ионные разряды с предупреждением.
- Каждый вылет завершается командиром. Шесть типов боссов с разными атаками и второй фазой.
- Три медали за миссию: победа, бонусная задача, полёт без потери жизней. Миссии можно переигрывать.
- Пять видов оружия из падающих капсул. Найденное оружие сохраняется; повторный подбор повышает мощность в текущем вылете.
- Ангар: шесть постоянных улучшений, боевой дрон, три ракеты с разными характеристиками.
- Бесконечный режим с нарастающими волнами, боссами и отдельным рекордом.
- Новое главное меню, карта кампании, ангар, настройки, пауза и итог миссии.
- Прогресс хранится на устройстве. Перенос между устройствами пока не предусмотрен.

## Управление

Телефон: двигай палец по свободной части экрана. Ракета по умолчанию стреляет автоматически. Кнопка «ИМПУЛЬС» очищает вражеские выстрелы и повреждает противников. Заряд восстанавливается со временем. Ручная стрельба включается в настройках: удерживай «ОГОНЬ» вторым пальцем.

Компьютер: WASD / стрелки — движение, пробел — импульс или стрельба, 1–5 — оружие, P / Esc — пауза.

При переходе в другое приложение полёт ставится на паузу. Есть три сложности, звук, музыка, вибрация и уменьшение мерцания.

## Запуск и проверка

Браузерная версия не требует дополнительных пакетов. Нужен Node.js: npm start для запуска, npm test для проверок.

Локальный адрес: http://127.0.0.1:4173/imran-space-game/

33 проверки покрывают кампанию, прогресс, покупки, оружие, боссов, столкновения, двухпальцевое управление, паузу и недоступное хранилище. В браузере проверены размеры 360×640, 390×844 и экран компьютера. Это не заменяет тестирование на физических телефонах.

GitHub Pages: main, / (root), .nojekyll в корне. Все изображения локальные. HTTPS-версия сохраняет публичные файлы для офлайн-запуска после первой успешной загрузки.

## Android и iPhone

Подготовлены проекты Capacitor 8 с локальной игрой, портретной ориентацией, своими иконками и заставкой, паузой при сворачивании и вибрацией. Статус и инструкции: [RELEASE.md](RELEASE.md).

Архив mobile-sources-v3.zip содержит папку mobile с мобильными исходниками. Распакуйте её рядом с index.html. В полной локальной поставке исходники уже находятся в mobile/.

APK/AAB/IPA, подпись, проверки на устройствах и публикация в магазинах ещё не выполнены. Для iOS нужен Mac с Xcode; для Android — Android Studio и SDK.

## Графика

Композиция меню создана встроенным ImageGen. Имран на ракете основан на референсах пользователя. Запросы, режим и файлы: [art-prompts.md](art-prompts.md). Иконка и мобильная заставка выполнены в SVG. Графика и код других игр не копировались.
