# Имран: Звёздный защитник

Космическая аркада для телефона и компьютера. Имран сидит верхом на ракете и сражается с флотом пришельцев.

**Играть:** https://berdinov81-alt.github.io/imran-space-game/

## Что изменилось в версии 2

- Новые изображения Имрана на ракете, космоса и шести разных кораблей.
- Пришельцы с разными траекториями, бронёй и атаками вместо метеоритов.
- Оружие падает сверху. Подбери капсулу, чтобы открыть его; повторный подбор повышает мощность.
- Лазер, веер, плазма, ракеты и луч. Новое оружие открывается во время полёта.
- Каждый этап заканчивается боем с боссом. Следующий этап начинается после победы.
- Боссы меняют поведение по мере потери здоровья. Следи за предупреждениями перед сильными атаками.
- Выбор сложности, щиты, лечение, рекорды и пауза.

## Управление

Телефон: коснись свободной части экрана и двигай палец, чтобы вести ракету. Вторым пальцем удерживай «ОГОНЬ». Оружие выбирается в панели снизу.

Компьютер: WASD или стрелки — движение, пробел — стрельба, 1–5 — оружие, P — пауза.

После переключения в другое приложение полёт ставится на паузу. Нажми ▶, чтобы продолжить. Для запуска на телефоне открывай обычную ссылку в Safari или Chrome.

## Локальный запуск

Нужен Node.js, дополнительные пакеты не требуются. Запуск: npm start. Проверки: npm test.

Локальный адрес: http://127.0.0.1:4173/imran-space-game/

GitHub Pages: ветка main, папка / (root). Все файлы и изображения лежат рядом с index.html; .nojekyll сохраняется в корне.
