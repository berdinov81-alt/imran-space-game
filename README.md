# Имран: Метеоритный штурм

Браузерная космическая игра для телефона и компьютера. Помогай Имрану на ракете разбивать метеориты, собирать звёзды и ставить рекорды.

**Играть:** https://berdinov81-alt.github.io/imran-space-game/

## Управление

- Телефон: коснись свободной части экрана и двигай палец, чтобы вести ракету. Вторым пальцем удерживай кнопку «ОГОНЬ».
- Лазер, плазма и мультивыстрел переключаются кнопками снизу.
- Компьютер: WASD или стрелки — движение, пробел — стрельба, 1/2/3 — оружие, P — пауза.
- После переключения в другое приложение игра ставится на паузу. Нажми ▶, чтобы продолжить.

Открывай ссылку в Safari, Chrome или другом обычном браузере. Предпросмотр HTML в мессенджере может показывать только обложку.

## Локальный запуск и проверки

Нужен Node.js, установка дополнительных пакетов не требуется.

```sh
npm start
npm test
```

Локальный адрес: http://127.0.0.1:4173/imran-space-game/
